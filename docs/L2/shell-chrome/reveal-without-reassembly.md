## 4. The invariants the integration must hold

1. **`INV-R` — no reveal transition may be applied by a re-assembly.** On the gesture path the record is untouched (`0 setLayout`), the frame identity is untouched (`0 loadEnvelope`), and the paint is **idempotent** (a transition to the same set writes nothing). This is `F7`'s repair as an invariant, not an implementation note.
2. **The mirror-only law.** ⟨**SUPERSEDED IN PART `2026-11-16`, §10** — carrier 1 is now the live DOM class the stylesheet reads, not the `state-slice` op; the sentence below is kept VISIBLE as the superseded reading (`RCA-8(c)`). The remainder stands: still exactly TWO carriers, still no re-assembly, and still no `classList` poke was needed (the write is a composed `className`)⟩ The reveal reaches the DOM through the two carriers of §2 and nothing else. Any third carrier (a `classList` poke, a host-authored element, a direct `style` write per zone) is a review finding (`D-8`, `ASM-RR-1`).
3. **ONE predicate, two carriers.** `zoneMirrorClasses` is the only spelling of the three mirror class names; the assembler and the paint both reach it (`ASM-U1b-10` precedent). A paint that re-derives `is-collapsed` from anything but `zoneCollapsedOf` breaks the equality limb `P`(p2) drives.
4. **THE ONE RULE: every assignment to `revealedZones` is followed by the paint.** Today those are `onRevealChange`'s write (`READ` `:935`) and `commitPaneDrop`'s clear (`READ` `:3711`). `cancelPaneDrag` gets **nothing** — the controller's `cancel()` changes the set through `setRevealed` → `onChange` → the paint, and a second host-side paint there is a defect (limb `T`(t2) counts one paint, exactly).
5. **The paint is a transition write.** It runs per reveal SET change, never per frame; the controller already guarantees that, and the live diff keeps it honest if a caller paints twice.
6. **No re-render is deferred and no latch is added** (`ASM-RR-4`). A deferral latch would let a future re-assembly on the gesture path pass silently instead of being measured.
7. **`F8` is not worsened** (carried): `declaredPlacesOf` still re-spells `defaultOrder ?? seq` (`READ` `:3798-3799`) while its own comment (`READ` `:3789-3791`) denies it. This unit does not touch that method.

## 5. Failure and boundary states

| State | Required behaviour |
|---|---|
| no runtime (a pre-boot or test host) | the class half is a **no-op**; the track half still projects; **never a throw** |
| a throwing `nodeState` | `currentZoneMirror` answers `{ classes: [], collapsed: '' }` — the paint proceeds fail-soft, never throws |
| a throwing `applyCommand` | caught by the paint's class half; the track half still runs; never a throw |
| a zone container absent from the LIVE graph | its diff sees `[]`; an empty desired list writes nothing, a non-empty one writes one op the ENGINE refuses (fail-soft) |
| the reveal set is `[]` on both sides | 0 ops (the gesture start and every repeat move) |
| a placement-equal drop into an EXPANDED zone | **ZERO `setLayout`s** (the record law is unchanged) **AND** the painted clear removes `is-revealed` — the LATENT defect this unit closes |
| a cancel mid-gesture | exactly ONE paint, through the controller's own `onChange`; 0 loads |
| a cross-zone crossing | 2 ops (the zone left, the zone entered); 0 loads; 0 record writes |
| a hostile reveal carrier (`__proto__`, a duplicate, a non-finite index) | the predicate's `isLayoutZoneName` filter IGNORES it; the set is a `Set`, so a duplicate collapses; never a throw |
