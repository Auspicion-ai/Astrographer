## 4. The invariants the integration must hold

1. **`INV-E` — no pane update may be applied by a re-assembly.** `0 loadAppGraph` / `0 mountOperator` / `0 refresh()`, counted on the host. **The row must be able to FAIL:** four mutants (m1 `refresh()`, m2 `loadAppGraph`, m3 `mountOperator`, m4 a no-op paint) are each measured RED on the same harness before the zero is a reading.
2. **ONE pane, ONE root.** A fire for X applies X's root and nothing else; every other materialized root is the **SAME OBJECT** across the paint (identity, not equality). A shape-equal re-render applies NOTHING (`reason:'unchanged'`).
3. **Every absence is a DECLARED word.** `not-a-pane` / `not-enabled` / `operator-scope` / `not-mounted` / `no-runtime` each answer their own word, throw nothing, and **never fall back to a re-assembly**. `operator-scope` is what keeps `B-9`'s surface out of this unit.
4. **The two arms cannot diverge.** ONE registry, TWO declarations, ONE dispatch: `subscribeRecord` = `subscribe` + a mark; `deliver()` fires through `fire`. The row pins the SAME handler instance across both arms, and byte-equality of the authored frame + `applied` across two identical hosts.
5. **The alias is closed in BOTH directions.** `fill()` lands a copy: mutating the port's answer cannot rewrite what the client holds, and mutating the held reading cannot rewrite the port's answer. The copy is not a re-read (exactly one port read per `fill()`) and refuses nothing (a malformed entry stays held; `displayOf` still judges it `null`).
6. **`B2-ADV-04` is not re-broken.** Exactly ONE `installDisplayCrossing` call site and ONE `client.subscribe` for the record arm. A second registration would double every push.

## 5. Failure and boundary states

| State | Required behaviour |
|---|---|
| an id no pane declared interest in | `{fired:false, handlers:0, reason:'no-listener'}` — **never a throw** (the `pane-registry.ts` swallow is the precedent, not its `requireKnown` throw) |
| a handler that throws | contained per handler; the others still run; `fire` never throws; the report counts the handlers that STOOD |
| a handler that withdraws itself mid-dispatch | the pass continues (SNAPSHOT iteration) |
| a degenerate id (`null`, `NaN`, `''`, an array, a symbol, a function …) | `fire` answers the declared no-op; `subscribe` answers a total release and registers nothing; **neither census gains the id** |
| `deliver()` over the shipped empty record-interest set | `[]`, never a throw |
| a pane the registry has never heard of | `not-a-pane` |
| a registered but DISABLED pane | `not-enabled` (the ENABLED census excludes it — not `not-mounted`) |
| an `operator`-scope pane | `operator-scope`; the **site** keeps `void host.refresh()` under a `⟨B-9⟩` marker, and `B-9` deletes that branch |
| an enabled app-graph pane with no materialized frame | `not-mounted` |
| a host holding no runtime | `no-runtime` (mounted-ness is a fact of the runtime's root set, so the absence of the ROUTE is its own word) |
| a port that throws / rejects / answers a non-record | the standing reading is INTACT (a failure is not an absence, `B1-ADV-04`) |
