- **Four keys, the fork's, unchanged** (`READ` `src/shared/types.ts:415-421`): `{kind, nodeIds, edgeIds, store}`, in that order; `cursor`/`wikiId`/`timestamp`/`type` never cross (`ASM-B4-1`). A re-read's answer is checked against the SAME four keys (`F-9`): `{}`, `{kind:'structural'}`, a fifth key or an empty `store` is "no descriptor", not a payload — **and so is a `store` that is merely non-empty but not the ORIGIN (`F-12`, this pass)**.
- **`announced` is the module's ONE new status member** and it exists because the contract does: a connection that has not announced has NO head, so its frames cannot be judged (`ASM-B4-5`). `connected: true, announced: false` is a truthful state and is NAMED rather than inferred — there is no timer, no timeout and no default head.
- **`status()`/`census()` build a FRESH object per call**; `status().failure` is ALWAYS the typed `EngineUnavailable` with its `cause` (`engine-rag-store.ts:111-123`), never a bare wire error. `frames` is a closed partition (`seen` counted first; a retired connection's frame is excluded before counting, `F-1(c)`). **`status().cursor`/`position` are the LIVE CONNECTION's watermark (`F-11`) and there is no other**: a retired connection's position is not the feed's to report, and a fresh connection's position is `null` until its own announcement (measured: `c4(f)`, `c1(b)`).

## 4. The mapping, the state machine, the wiring

**4.1 The frame families** (`READ` `../Gnosis/src/bin/gnosis_server.rs:970-1040`; the `event:` label ≡ the data's `type`, `:966-969`):

| `event:` | `data:` (exact key set) | What the consumer does |
|---|---|---|
| `cursor` | `{"type":"cursor","cursor":"<decimal>"}` — cursor-FIRST, every connection (`:983-986`) | **emits NOTHING**: validates a TWO-key set + a canonical decimal inside `u64`, counts `frames.cursor`, advances THIS connection's watermark, **records THIS connection's head and STARTS its re-read** (`ASM-B4-5`). `c1` |
| `change` | `{"type":"change","cursor","wikiId","kind","nodeIds","edgeIds","timestamp"}` — one per committed entry (`:936-950`) | validates the exact seven-key set, maps to the four-key descriptor, and **either HELD (the answer is not in yet) or judged** by §2.3. `c2`, `c3`, `c4` |
| anything else | — | a **typed refusal**: `frames.refused`, no descriptor, **no teardown** (`u4-cursor-paged-reads.md:521-524`) |

*The engine's own discipline, read at that checkout:* `cursor` is `entry.seq.to_string()` (`:939`); `wikiId` nullable (`:940`); `kind` = the entry's `op` literal from the **closed 20-token set** (`u4-cursor-paged-reads.md:512-517`); `edgeIds` the six-term canonical JSON-array strings (`:942-943`); `timestamp` ISO-8601; the 100 ms poll loop has **no keep-alive, no `done`, no coalescing** (`:930`, `:1005-1032`); `text/event-stream` exactly (`:1035-1039`); and **"the feed has no request-side cursor today"** (`:972-976`, verbatim) — which is why §2.4 exists.

**4.2 The kind table — TWO LIMBS, AND THEIR ORDER IS THE RULE (`c3(a)`, `c3(c)`; `F-13`, the contract's own amendment).** **The FRAME decides first:** a `change` frame whose `edgeIds` array is **NON-EMPTY** maps to `structural` whatever its token — the graph moved, and the fork's reconciler takes its FULL path on exactly that condition (`READ` `src/renderer/content-reconcile.ts:374-375`, `:566`). **Then the TOKEN decides the remainder:** `content` = `update_fact` · `update_community_summary` (the two appended ops that rewrite node TEXT and nothing else); `structural` = the other EIGHTEEN — including `update_document`, which REPLACES the document's graph and can write `link`/`embed`/`crosslink` edges (`READ` `../Gnosis/src/store/mod.rs:3604-3634`), and `re_sync_embed`, which flips an embed edge's `state` (`:5733-5830`), so the old criterion ("rewrites node TEXT and moves no graph shape") is **FALSE** for both. **UNKNOWN → `structural`, emitted, counted** (`ASM-B4-2`), and the frame limb applies to it too.

**4.3 The state machine — every arrow is a row, and the ORDER is the whole of `ASM-B4-5`**

```
connect() ─▶ connects++ ; failure := null ; if a subscription is LIVE: DECLARED NO-OP (one socket, always — ASM-L2-2)
   └─ subscribeEngineStream(...) ─non-loopback│throws─▶ typed failure ; connect() never rejects (c6, c8) ; APPLIES NOTHING YET
   frame(event,data) [only if this connection is LIVE and its generation is current]
        ├─ label ∉ {cursor,change} │ bad JSON │ not an object │ type ≠ label ─▶ refused++ ; the stream STANDS
        ├─ cursor ─▶ exact 2 keys + canonical decimal ≤ u64 ─▶ cursor++ ; watermark := max(THIS connection's, n) ; EMITS NOTHING
        │      └─ FIRST announcement on this connection ─▶ head := n ; reconcileFor() STARTS (once per connect)   ◀ THE ANCHOR
        └─ change ─▶ changeFrameToPayload ─refusal─▶ refused++ ; else change++ ; unknownKind += known?0:1
              ├─ the gate is SHUT (this connection's answer has not reached the sink) ─▶ HELD, in arrival order
              └─ the gate is OPEN ─▶ cursor ≤ THIS CONNECTION's watermark ─▶ dropped++ (its re-read covers it) ; else watermark := cursor ; applied++ ; onChange
reconcileFor() ─throws│rejects│answers no 4-key ORIGIN-pinned descriptor─▶ settle: the SUBSCRIPTION IS CLOSED, typed failure (fail-closed)
             └─ answer ─▶ onChange(answer)  ◀ ORDERED BEFORE any applied frame ─ then gate := OPEN ; drain `held` in arrival order,
                            once, through the SAME judge — and STOP if the connection was retired mid-drain (F-10)
close() ─▶ generation++ ; the connection is ENDED (so a late callback cannot settle the feed) ; handle.close() ; total, idempotent
onError │ onClose ─▶ ONE ending, and only for the connection that is STILL LIVE: typed failure, live := null (F-10)
```

**Nothing retries**: no `setTimeout`/`setInterval`, no backoff, no poll, no second connection (contract §2.5, `D-82` clause 4). **The one place a frame waits is the in-flight hold** — `Connection.held`, mandated by limb 3 of the ruling ("no change frame is applied until the answer has been delivered"): it is one-shot, in arrival order, drained the instant the answer lands, discarded on fault/close, and it has **no timer and no re-arm**, so it is not the "queue" the contract's prose forbids (named upward in §9 `O-4`). **The watermark is the CONNECTION's, and that is a measured requirement, not a preference (`F-11`)**: `change_cursor()` is `epoch().to_string()` (`READ` `../Gnosis/src/store/mod.rs:2400-2413`, `"0"` on a fresh store), so a reconnect after an engine restart announces a head BELOW the retired connection's — a feed-lifetime watermark drops every frame of the restarted engine for ever, killing the live path the moment a reconnect succeeds. Monotonicity holds **within** one connection only, and only a connection's own head licenses §2.3's "the re-read covers it" drop.

**4.4 The wiring — four sites in `src/main/main.ts`.** (1) **construction**, beside the two engine proxies and after the CRUD proxy (`READ` `:830`, `:839`, `:874`), INERT; (2) **`reconcile`** = the FULL engine CRUD read: `listWikis()` (`READ` `:878`) then EVERY PAGE of each wiki's `listDocuments` (`READ` `:882`; the CRUD surface `engine-crud-rag-store.ts:772-779`), answered as ONE `structural` descriptor — paginated (`RECONCILE_PAGE_SIZE = 200`, `:311`) and page-bounded (`RECONCILE_MAX_PAGES = 50`, `:312`) because the list IS paged (`F-4`; `c9(h)` pins both); (3) **the sink** = `backend.broadcast(IPC_RAG_STORE_CHANGED, descriptor)`, the EXISTING channel (`READ` `types.ts:403`) — no new constant, no `preload.ts`/`types.ts` byte; (4) **`void engineChangesFeed.connect()` AFTER the window and after its content has loaded** (`main.ts:1379`, below `await win.loadFile(...)`), plus **`close()` on `app.once('before-quit')`** (`:895-896`).
