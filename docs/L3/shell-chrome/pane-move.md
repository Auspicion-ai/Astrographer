**Pinned signature** (single, overload-free, TOTAL, pure):
```ts
export function panePlace(input: { entry?: PaneLayoutEntry; defaultOrder?: unknown; seq?: unknown }):
  { declared: number; effective: number }
```
**Pseudocode.** 1. `finite = (v: unknown): v is number => typeof v === 'number' && Number.isFinite(v)`. 2. `declared = finite(input.defaultOrder) ? input.defaultOrder : finite(input.seq) ? input.seq : 0`. 3. `effective = finite(input.entry?.index) ? input.entry!.index : declared`. 4. `return { declared, effective }`. No registry, no state, no throw.
**The comparator chain — EXPLICIT, because `A`(a2)'s tie arm and `C`(c3) both depend on it:** `order(a,b) = a.effective - b.effective` (**1º** the pane's only placement word) `|| a.declared - b.declared` (**2º** a stated-place TIE breaks at the DECLARED place) `|| a.seq - b.seq` (**3º** registration order, the total-order floor). Every term is `NaN`-free by construction (`panePlace` answers finite numbers; `seq` is the `forEach` index at `:237`). The **superseded** chain is `a.index - b.index || a.seq - b.seq` (`READ` `:247`): it breaks ties at `seq`, which is exactly what `A`(a2)'s tie arm measures (`[z, x, y]` vs the required `[z, y, x]`).
