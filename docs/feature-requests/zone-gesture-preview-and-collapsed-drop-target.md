## 1. What this request asks, in three clauses

1. **A PER-MOVE PREVIEW OUTPUT FOR A HOST'S RESIZE GESTURE — the capability the family's own machinery does not carry on its adopted path.** A consumer that composes `createResizeController` over `createGestureSession` (the family's own recommended pair) has **no supported way to present the in-flight size while the pointer is down**: the controller reads its `sizeFor` seam **once, at the committing terminal**, and the session's only mid-gesture hook (`onMove`) hands the caller a **handle** — a value holder, not a presentation seam. **The ask, in three limbs:** **(i)** an optional **per-move PREVIEW sink** on the resize controller — a caller-supplied `onPreview`-shaped seam invoked **per observed move**, carrying the **family's own clamp** applied, with the **one-commit-per-gesture rule preserved** and **never a per-move persistence write**; **and/or (ii)** a **documented composition** in which `createGutterAffordance` **ACCEPTS an existing controller/session** rather than installing its own — so the two modules are **layers, not alternatives**; **and (iii)** an **explicit declaration if the family intends the preview to be the caller's own** — so a host reading the terminal-only behaviour knows it is **by design, not a gap**, and neither clause (i) nor (ii) is owed.
2. **A DROP-TARGET GEOMETRY SOURCE FOR A COLLAPSED ZONE, AND A GESTURE LIFETIME THAT SURVIVES A RE-RENDER.** A consumer cannot express a **drop target for an EMPTY zone**: the family's own track record answers the caller's `emptyToken` for an empty member (and the host writes that token inline into the grid), so the zone's own box is **degenerate by construction** and any hit-test on it refuses — while **the zone's CELL still exists in the grid**. Separately, a **hit-testable** zone box does not by itself make a cross-zone drop commit: the host's own reveal write re-renders the graph, the captured element is **replaced**, and the family's session has **no documented route to survive or re-claim capture** across that replacement. **The ask, in three limbs:** **(i)** a **zone-slot geometry seam** — a family-provided reading of a member's **own CELL/slot box** that exists **while its track is collapsed**; **and/or (ii)** a **documented route** (or a **declared prohibition, with the remedy named**) for a gesture whose captured element is replaced mid-flight **by the host's own re-render** — the family should say whether a host **must not re-render during a gesture**, or **how the session is re-established / re-claimed**; **and (iii)** an **explicit statement if the collapse-to-zero-extent coupling is intended**, in which case a consumer needs **the sanctioned way to ask for the cell**.
3. **A ONE-BLOCK STATEMENT OF WHICH OF THESE ARE THE CALLER'S OWN.** Each of the two clauses above admits a "the family deliberately leaves this to the consumer" answer, and that answer is **an acceptable resolution for both** — but it must be **stated**, alongside whether the two modules of clause 1 are intended to compose **with each other** or only **side-by-side**, and whether a `0px` track is intended to be the **whole** geometry a consumer can read for a member. **A named boundary is a usable contract; a silent one costs an adopting fork a probe pass per integration.**

## 2. The gap, stated exactly

**Clause A — the adopted composition has no per-move output, and the one member that HAS one cannot ride it.** The family's resize surface is three modules with **two different lifecycle owners**:

- **`gutter.ts` → `createResizeController`** owns an **arithmetic decision taken at the terminal**: its own header states the module *"only reads the values a gesture carries. Its one output is an arithmetic one — a value read at the terminal, narrowed into the caller's own pair, and handed to the injected sink at most once"*, and its option set carries **exactly one value-bearing seam** — `sizeFor?: (element, gesture, axis) => unknown` — whose **only call site is the committing terminal's path**, ahead of **the one write** (`commit`, *"reached only from a committing terminal and at most once per gesture"*).
- **`gesture-session.ts` → `createGestureSession`** owns the lifecycle: it establishes, opens three tracking listeners, and delivers **one mid-gesture turn** — `onMove?: (gesture: GestureHandle) => void`, *"the session's one legal handle channel"* — whose argument is **the per-gesture handle** (`active`, `outcome`, `id`, `value`, `set`, `element`), i.e. **a holder the caller writes into**. Nothing in the session's surface presents a value to an element or a style sink.
- **`gutter-affordance.ts` → `createGutterAffordance`** is the **one member of the family that carries a live preview** — `PreviewState {value, token, valid, resizable}` with *"The CLAMPED value for this observed move"*, written through `applyPreview`, counted by `stats().previews` — **and it is not composable with the controller as adopted**: it requires **its own full option set** (`session` REQUIRED, `source` REQUIRED, `element` REQUIRED, `target` REQUIRED, plus the nine required seams), it **installs its own move listener** on its element, and it **exposes the controller it composed** (`readonly controller`) — so adopting it **alongside** the host's controller means **two listeners on one element and the displacement of the host's controller**, which is exactly the condition the fork's two `DECLINED FOR THIS UNIT` records already carry (`unit-zone-replacement.md` `§3.6.2`; `§4.0` blockers 1/2). **Both factories are `imported by NOTHING` in this fork's `src/**`** (`unit-zone-replacement.md` `§4.0`'s tree clause; re-verified by this pass, below).

**Clause B — two INDEPENDENT mechanisms, and the second one survives a fix of the first.**

- **(B1) A COLLAPSED MEMBER HAS NO READABLE BOX.** The family's track arithmetic is pure token work: **`census.ts` → `computeTrackVars`** asks **`zones.ts` → `isEmpty`** for the member and, where empty, emits **`zones.ts` → `trackFor`'s** answer for it — which is the caller's **`emptyToken`** *"byte for byte: never trimmed, never case-folded, never prefixed or suffixed and never replaced by a mechanism literal"*. The **consumer** then writes that token into the grid. **A member whose track is the caller's `emptyToken` therefore presents a box of ZERO EXTENT to every geometry reader the family offers**, and a hit-test on that box refuses **by construction** — while **the member's own grid CELL is still a cell of the grid**, and the family offers **no reading of it**: the whole `census`/`zones` surface is **three value exports + three type declarations** and reads **nothing but its arguments** (it never sees a layout, an element or a rect).
- **(B2) A CAPTURED ELEMENT REPLACED MID-FLIGHT CANCELS THE GESTURE, WITH NO NAMED ROUTE BACK.** When the target box **is** non-degenerate, the consumer's own reveal write **re-renders the graph**; the element the session captured is **replaced**; the capture is then **lost**, and the session's record is taken off its active state (`gesture-session.ts`'s terminal and cancel paths both write `record.active = false`; the refusal path re-checks it with `if (record === null || !record.active) return refuseTerminal('no-gesture')`). A later `pointerup` on the **replacement** element is therefore **inert**: the tracking listeners were bound to, and detached from, **the element the gesture established on** (`detachTracking(record)` uses `record.element`). **The family's session offers no re-establish, no re-claim and no documented prohibition of a host re-render during a gesture** — the install ledger is keyed by object identity and **refuses a second install of the same element** (`ledgerKnows(element)`), which the fork has already filed as its own item (`FOUNDATION-INSTALL-COLLISION-ONE-ELEMENT-ONE-SESSION`) and which is why "just install the replacement" is **not** an available consumer route either.

**THE FALSIFIED HYPOTHESIS — stated because this request's credibility rests on it.** **The missing `createRelocateSession` composition is NOT the cause of (A) or (B), and this request does NOT ask the foundation to fix anything its own modules do not cause.**

- The fork's cross-zone machinery is **already correct**: `movePane` **relocates** (it windows the moved pane into the target zone at the requested index **and renumbers the vacated source zone**), `legalZonesForScope(scope)` answers the **scope legality**, and `insertionIndexForPoint(point, zone, slots)` derives the index **inside the target zone's own bounds** — all **fork-side policy** the family's own contract deliberately leaves to the caller (`unit-zone-replacement.md` `§3 row 6`'s policy column: *"scope legality … order derivation … the module orders nothing"*).
- The family's relocate session takes a **caller-MEASURED candidate list** (`CandidateFor {candidate, distance}`, *"the scalar the CALLER measured"*), so **a geometry refusal arrives there as an EMPTY SET and is simply REPRODUCED**: composing `createRelocateSession` over a `candidatesFor` seam that cannot produce a candidate for a collapsed zone **changes nothing** — the session would compare distances it was handed, and it would be handed none. **B1 is upstream of the session**, in the track/cell coupling.
- **(B1) and (B2) are independent**: fixing the box source still leaves the re-render/capture lifetime, and fixing the lifetime still leaves a collapsed zone with no target box.
